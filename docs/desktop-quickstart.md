# 文序 Windows 桌面版

当前版本：1.0.0-preview.4，教案预览与区域标准开发预览版。

## 使用

1. 将 ZIP 完整解压到本机目录。保留 `Wenxu.exe` 与 `_internal` 目录的相对位置，双击 `Wenxu.exe`。
2. 点击“打开文档”，选择 DOC 或 DOCX。需要本机安装兼容的 WPS；不需要安装 Python、Git、WSL，也不需要浏览器。
3. 点击“按金标准整理”。默认按四组教案区域处理，页面主体显示结果，无需先选栏目。需要微调时点击“调整金标准”。
4. 通过页码核对预览，“查看原稿”在同一画布切换；返回结果时取消勾选即可。
5. 核对后点击“保存副本”。查看原稿时按钮显示“保存修改后”，保存的始终是当前结果。DOC 仍保存为 DOC，DOCX 仍保存为 DOCX。原稿不能被覆盖。

“更多 → 局部编辑与版本”可打开详细范围、格式和历史版本；撤销、模板管理和旁批明细也在“更多”。关闭程序后不会保留会话，请及时另存结果。
预览仅显示页面，局部编辑需在更多中选择范围；“查找指定文字”须选中搜索结果，可按 Ctrl 多选。

## 四组教案标准

| 区域 | 默认字体字号 |
| --- | --- |
| 表格列头与行头 | 宋体小五（9磅） |
| 教学内容一般文字 | 宋体小四（12磅） |
| 师生活动、设计意图填写内容 | 宋体小五（9磅） |
| 课堂小结、作业布置、板书设计填写内容 | 宋体五号（10.5磅） |

特殊三行的填写内容优先于一般列规则；行头仍为小五。区域按列头含义定位，支持换列序、重复列头和明确归属的合并单元格。无表头续表或合并归属不明时提示核对，不猜固定列号。无关表格保持原样。

preview.4支持用`Summary`、`Homework`分别标注课堂小结和作业布置，忽略大小写、空白和既有分钟标记。仅在环节标签位置完整匹配，不把教学正文中出现的这些单词当成特殊行。真实合并归属冲突仍提示核对，已知冲突不再叠加“没有教学过程／没有规则”的连带提示。

教学内容中的标题默认保留原格式，识别结果及例外可在“更多 → 本次识别与保留项”查看；可在调整标准时明确选择标题同教学内容字号。其他未指定属性保持原样。

默认四组规则是本次明确指定的标准，尚未选择实际模板文件。导入模板后切换为该模板的标准；无旁批仍自动提取现有样式，有旁批仍需先校准模板。调整已导入模板的四组标准会修改独立模板候选，校验后展示模板预览，核对并采用后再应用到当前教案。取消或失败保留旧标准。跨会话使用修订后的实际模板，请导出模板包。

## 按教案模板整理

1. 点击“更多 → 导入模板”，选择DOC、DOCX或此前导出的`.wenxu-template`模板包。工作教案与模板分别保存，导入模板不替换当前教案。
2. 无旁批且分类、有效样式明确时，自动采用现有样式。分类不明、同类格式混合或无法确定的继承/主题值会显示待核对。
3. 有旁批时点击“核对模板”，查看原文、对应内容、实际作用范围、当前有效格式和目标格式。明确的常用要求自动提取；未理解内容、范围不明确、局部例外及非格式要求需显式处理。
4. “设置格式与范围”用于明确规则，“正文与标题分类”用于纠正角色；必要时新增局部例外或保护范围。人工事项与不适用项必须填写理由及阶段，模板本身尚需人工处理的事项仍会阻止采用。
5. 点击“校验并修正模板”，程序保存原格式候选并重新检查。到“模板预览”查看结果，确认后“采用此金标准”。未解决项不能通过勾选预览绕过。
6. 回到工作教案，点击“按金标准整理”。局部或保护范围需在新教案中重新对应，不能直接复用模板段落序号。得到v1后可继续修改得到v2，版本记录模板来源。文档已符合模板时不新增空版本，但后续实际修改仍沿用此次选择的模板与保护范围。
7. “更多 → 未自动验证事项”保留旁批的原文、理由与适用阶段。有未验证事项时会在结果说明提示，不能将格式完成理解为全部业务要求已经检查。
8. 模板核对窗口可“另存模板文件”；主界面“导出模板包”保存实际DOC/DOCX和来源记录，便于下次导入。再次导入会核对文件指纹并重新检查实际属性。普通教案通过原有“另存副本”保存。

分类纠正只改变操作范围，不等于写入Word标题样式。双击内容仅在页面文字能唯一对应时定位预览，否则显示段落/表格上下文供核对。已有保护范围会继承到后续修改；需要改变时通过“查看保护范围”明确解除。

## 运行条件与边界

- Windows x64；当前包需在目标 Windows / WPS 组合上验证后再作为正式稳定版使用。
- 本机 WPS 提供 KWPS 自动化接口，目标字体已安装。Microsoft Word 单独安装暂不能替代此接口。
- 旁批解释为有限语法，不保证任意自然语言自动理解。带回复或已解决状态等尚未验证的现代批注会明确提示；普通无回复、未解决的扩展元数据已支持。读取异常不会被当作无旁批。
- 文本改写、外部课表核对、删除首页、打印设置和写入Word标题样式仍不自动执行；对应要求须处理或明确保留适用阶段，不能冒充通过。
- 若提示 WPS 正在处理其他文档，先保存并关闭 WPS 中打开的文件，再重试。程序不会强制关闭您的 WPS 文档。
- 继承当前核心的范围：10 MB 以内、单节、渲染后不超过 50 页，拒绝加密或含宏等未经验证的文档。
- 缺少原文字体时会提示；即使字节不变，也不能保证跨不同字体环境的版式一致。
- 文档由本机引擎处理，程序不提供上传、账号或遥测功能。用户文档不随分发包提供。
- 这是免安装预览包，尚未提供自动更新、安装器、数字签名或干净机器的兼容承诺。删除解压目录即可移除程序，不影响另存的文档。

## 开发与验收

桌面维护线为`lts/windows-desktop`，本次功能开发位于`codex/lesson-template-workflow`；稳定维护规则见仓库`docs/specs/windows-desktop-lts.md`。

在 Windows Python 3.12 x64 中：

```powershell
python -m venv .venv-desktop
.\.venv-desktop\Scripts\python.exe -m pip install -r requirements-desktop-build.txt
.\.venv-desktop\Scripts\python.exe -m unittest tests.test_desktop
.\.venv-desktop\Scripts\python.exe desktop_app.py
.\.venv-desktop\Scripts\python.exe scripts/build_desktop.py
```

可执行包的合成文档自检：`Wenxu.exe --self-test D:\WenxuChecks`。自检只生成新样例和结果，不读取用户私有文档；覆盖打开、普通修改、模板自动提取、按模板整理、模板包再导入、保存与版本，输出包括验收JSON和窗口截图，依赖实际WPS。
正式分发前需完成干净 Windows 机器验收，并处理第三方再分发许可及签名。包内 `THIRD-PARTY` 保存依赖许可与元数据，`build-info.json` 记录版本。
