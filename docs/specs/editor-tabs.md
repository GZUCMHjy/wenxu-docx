# 字体反馈与分栏交互

日期：2026-09-22。分支：`codex/fix-editor-font-feedback`。从已核对的 master `d9c42f3` 创建，承接已推送的原格式保真实现 `1fff936`。

## 问题与目标

用户反馈选择字体后看不出变化，页面信息过多。旧界面需要先加入清单再执行，而且上方始终展示未修改的导入基线，最新结果位于下方；用户可能把基线当成修改结果。此判断来自实际代码路径，不推断用户具体点击了哪个控件。

本地独立检查确认正文改字体可写入实际保存文件，并产生渲染变化。本轮调整 UI 和结果反馈，不改变原格式编辑、公式保全或校验契约。

合成 DOC 浏览器回归另复现字体校验误判：替换最后一处旧字体后，WPS 删除不再使用的字体声明。校验只允许在本次明确改字体时删除无任何剩余引用的声明；扫描所有 XML 部件中的引用（包括样式、主题、页眉），现有声明元数据和仍被引用的声明继续严格保留。替代字体别名仍有引用时也阻断，除非该引用有保留的同名主字体声明。此修复属于字体操作交付路径，不放宽正文、公式、图片或其他格式校验。

## 实施计划

1. 用已保存文件的实际属性和独立预览验证字体写入，排除只看控件值或结构快照造成的误判。
2. 拆成“编辑”“预览与下载”“历史与高级”三个 Tab；默认只显示编辑必需控件，低频操作折叠。
3. 编辑页提供字体、字号、作用范围和当前字体；选好后直接“应用并预览”。默认保持原样，选择本身不修改文件。
4. 应用成功自动选择最新版本并切到预览，显示实际操作摘要，定位第一个变化页，按需开启同步页码的前后对比。没有变化时明确提示，不制造新版本。
5. 保留可选组合清单、局部例外、保护与冲突阻断；当前设置和清单共同构建同一冻结计划，不能静默忽略未加入清单的控件值。
6. 验证切换 Tab、清单取消、版本切换、撤销和更换文件的状态隔离；跑真实浏览器下载校验、单元回归和代码评审，更新 WSL 服务。

## 验收

- 字体一键应用后，下载文件目标字体正确，未指定属性保持；渲染确实变化时显示变化页。
- 未选择属性不能执行；重复应用已满足的设置明确提示无变化。
- 编辑页不展示整篇对照或技术检查表。默认结果只显示当前选定的一页；原稿核对进入高级页面。
- Tab 切换不应用修改、不丢失待设置值；清单冲突能取消解除，实际执行使用最新状态。
- 新结果仍需查看预览后确认下载；不同版本、不同文件不沿用旧确认。
- DOC/DOCX 按原格式输出，原始上传文件保持；真实文件及派生数据仅在仓库外本地验证。

## 范围展示简化（同日追加）

用户要求去掉“范围详情与排除”。直接移除逐段明细与移除命中控件，不换成另一张同类表。编辑页仅显示有普通文字的命中段数及当前字体；空段和仅对象段继续保留在内部模型，不列入这个文字段数。

范围分类仍是产品支持的固定分类；具体匹配按每份文档的样式、大纲与表格结构动态计算，菜单仅展示有文字的已识别分类。不存在的标题级别/表格选项不展示；局部定位方式也按表格/栏目是否存在提供。识别不确定的内容仍为待归类，不假装任意语义理解。局部例外选项并入原有组合清单，选区保护移到历史与高级，保全规则不变。
