# 预览优先与教案区域标准实施计划

日期：2026-10-18。用户已授权实现此前的[界面设计](lesson-preview-ux.md)及[四组区域标准](lesson-template-calibration.md)。沿用现有功能分支与原格式执行器，保留用户本地IDE文件。

- [x] 区域识别：基于逻辑表格网格与教学内容/师生活动/设计意图列头定位教学过程表；识别重复表头、行头、特殊行和合并填写区。范围不明时不按物理列号猜测。
- [x] 区域规则：行列标题宋体9磅，教学内容12磅，活动/意图9磅，课堂小结/作业布置/板书设计填写内容10.5磅；字体与字号可调整，其余属性保留。内容中的标题默认保留为可见例外。
- [x] 标准与版本：复用冻结计划、实际保存后核验和保护范围；区域规则可在每份教案重新定位，记录本次标准来源。修改已选模板标准时必须落实到模板文件，不更改原件文字与表格结构。
- [x] 桌面：保留原生Qt，预览成为主体；主操作随状态在整理/保存之间切换。局部编辑、历史、旁批、模板管理收进更多操作；调整标准仅呈现四组规则与必要例外。
- [x] 验证：新增合成范围和Qt测试；覆盖换列序、行优先、重复表头、横纵合并、模糊结构、标题例外、原件保全、取消/失败不改标准及版本/保存流程。
- [x] 验收：171项回归通过；实际WPS授权DOC与合成DOCX检查、窗口截图、独立审查及preview.3可执行包自检通过。私有数据和截图只存仓库外。详见[验证记录](../verification/preview-regions.md)。
