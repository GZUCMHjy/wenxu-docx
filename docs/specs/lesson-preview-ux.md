# 教案结果预览交互细化

设计日期：2026-09-27；桌面实现更新：2026-10-18，preview.3。本方案承接[模板与金标准设计](lesson-template-calibration.md)。主界面已采用单画布预览、更多内的局部编辑与历史、四组标准设置及整理/保存主动作。原HTML仍为设计演示，实际效果由桌面程序渲染。

## 主界面

以修改后的教案为主要视觉对象。窗口只有紧凑的顶部操作条、大面积纸张预览和一行状态提示；默认不显示右侧栏目菜单、分类树、检查清单或一整套Word格式工具。

顶部只保留打开教案、当前金标准名称、“调整金标准”次级入口、对比和当前阶段的主要动作。**同一时刻只突出一个主要动作**：未整理时是“按金标准整理”，已有结果时换成“保存副本”。已保存后显示完成状态，不继续突出重复整理按钮。

| 当前状态 | 主要展示 | 下一步动作 |
| --- | --- | --- |
| 未打开教案 | 简单空白状态，沿用当前标准名称 | 打开教案 |
| 已打开，标准可用 | 当前文档页面与标准名称 | 按金标准整理 |
| 修改完成 | 修改后页面、简短结果状态 | 保存副本 |
| 正在对比原稿 | 原稿明确标为对比视图，可返回修改后 | 保存动作仍指向修改后副本，不能误保存原稿 |
| 存在异常 | 页面保留，显示一条待核对提示和入口 | 只核对相关位置与规则，处理后返回预览 |
| 已保存 | 当前结果继续可查看 | 按需调整标准、打开另一份教案或结束 |

原稿对比默认用同一预览位置切换，减少双栏缩小纸张造成的阅读负担；原稿和结果标签明确区分。更复杂的并排对照可以保留在更多操作，本方案不要求日常使用。

## 标准设置

点击“调整金标准”后才出现设置面板，按四组业务区域展示字体和字号。原型不增加通用栏目选择器，也不要求先从结构树选择段落。

1. 表格列头与行头：宋体小五，9磅。
2. 教学内容的一般内容：宋体小四，12磅。
3. 师生活动与设计意图内容：宋体小五，9磅。
4. 课堂小结、作业布置、板书设计内容：宋体五号，10.5磅；这些行的名称仍使用行头样式。

设置中只有“取消”和“应用并预览”两个结束动作。未应用的修改是草稿，取消或关闭时丢弃；应用成功后收起面板，回到完整结果预览。用户需要再调时重新打开，看到的是当前已应用的标准。

preview.3的实际模板修订保留一次必要的文件预览确认：设置应用后展示修正模板的完整页面，核对并采用后自动整理工作教案。该确认视图不铺开旧规则列表；取消保留此前采用的模板。未导入实际模板时，四组定义直接整理教案，来源记录为用户区域标准，不伪造模板文件指纹。

应用实际产品时，标准变更需落实到模板文件并通过已有保存后核验。只改变设置不会自行改写正文；原文字、顺序、表格行列/合并关系和对象必须保持。失败时继续使用上一个有效标准和结果，不让失败草稿冒充金标准。

规则说明、旁批、识别依据及范围纠正只在需要时展开；模板包导出导入、历史与临时局部修改放入更多操作。原型没有展示这些次级流程，不表示实际产品删除对应能力。

## 需要保留的业务边界

- 特定行填写规则覆盖一般列规则，行头与填写区分开；合并单元格按业务归属定位。
- 教学内容内部标题的独立字号仍等待用户明确，本原型的示例内容未放入这些未确认的标题例外。
- 用户明确的新标准覆盖被修订属性的旧旁批/提取值，旧要求保留作来源；不把原值反向刷回。
- 金标准修订与教案结果版本仍由系统分别追溯，主界面不展开两套版本列表。
- 当前模板包的保存/重新导入能力仍需保留。本原型不声称已经实现跨会话自动保存标准或Word分页。

## 原型与检查

设计源文件为`docs/prototypes/lesson-preview.prototype.html`，仅用于对话内的交互预览。内容是重新编写的合成教案，不读取用户文件、不生成Word输出，也不替代当前可执行程序。

重点检查：主界面没有常驻栏目树；修改标准后返回预览；字体字号变化不改文本和表格结构；取消不应用草稿；原稿对比不改变当前结果；已有结果时保存成为主要动作。界面需适应对话预览宽度，不发生水平溢出。
