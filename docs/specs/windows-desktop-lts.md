# Windows 桌面版与 LTS 维护约定

状态：1.0.0-preview.1 开发验收，尚未发布稳定 LTS。
基线：master / ba59a02971d641cf46aa3c0024dd5148cf5c4aac。
长期分支：lts/windows-desktop。

## 产品定位

文序是本地 Word 格式整理工具。用户打开文件、指定范围和格式、查看结果、另存副本。
首版为 Windows x64 原生窗口，以 PySide6 承载界面，直接调用现有解析、计划、补丁、原生 DOC 和验证模块。
用户不需要 Python、WSL、Git、浏览器或启动服务。DOC 保留 DOC，DOCX 保留 DOCX；原文件永不覆盖。
首发形态为免安装 ZIP，解压整个目录后运行 Wenxu.exe。WPS 为外部运行依赖，不随包分发；需要可用的 KWPS 自动化接口及目标字体。

## 首版交互

- 顶部：打开、撤销、版本选择、另存副本。
- 主区：文档逐页预览，可缩放、切换原稿对照；页数不同的两侧明确提示空页。
- 右侧：格式 / 页面两个标签；修改范围根据当前文件生成。支持正文、实际标题级别、表格、全文、具体段落、搜索结果及实际栏目。
- 字体显示当前范围的实际值；字体、字号、段落等未指定项保持原样。修改成功自动显示新版本；已符合要求时明确提示无需修改。
- 常用设置先呈现，附加段落属性放入折叠区。不展示对象 ID、原始计划、排除明细、调试 JSON。
- 耗时工作在后台串行执行，界面显示状态，处理中禁止切换文件或版本及重复执行。
- 输出版本核对预览后才能保存。打开新文件或关闭时提示未保存版本；处理中不能退出，以免破坏 Office 作业。
- 保存使用同目录临时文件与原子替换；禁止原稿路径及其链接别名。失败保留当前版本及原稿。

首版暂不移植网页端的自然语言规则批处理、参考文档导入与人工角色标注；这些核心能力保留原实现，桌面按验收后的需求逐项接入。
预览是页面图像，范围通过控件选择；不承诺直接在页面上拖选编辑。会话历史仅在本次运行保留。

## 模块边界

`desktop/controller.py` 管理本地文件入口、动态范围、保留原格式和安全落盘。
`desktop/window.py` 负责 Qt 控件、后台任务和页面预览，不重写 Word 处理逻辑。
`desktop_app.py` 是 GUI 入口。`packaging/windows.spec` 与构建脚本只收集运行文件，不收集仓库、测试文档或用户数据。
共用核心继续位于 `v06_*.py`；Windows Office 子进程隐藏控制台，仍沿用独占与原格式校验机制。

## LTS 规则

1. 此分支长期保留；稳定版目标为 1.0.x。当前 preview 不等于已承诺生产支持。
2. 1.0 稳定后只接收保真修复、崩溃与数据丢失修复、必要兼容更新、安全修复。新功能先在独立开发分支验证，不直接改变稳定用户流程。
3. 共用引擎修复以独立提交双向回补 master / LTS；不整分支合入实验功能。
4. 运行库固定版本，更新依赖后重跑原格式、公式/对象保全、字体、保存、Windows 可执行包验证。每次发布记录包校验和与依赖版本。
5. 正式发布需在无开发环境的干净 Windows 机器上验收，记录系统、WPS 版本、字体与样例结果。当前开发机测试不能代替该项。
6. 正式分发前确认现有依赖的再分发许可、安装/卸载流程与签名策略；支持年限、兼容 WPS 版本矩阵和升级渠道在 1.0 发布时确定，不提前虚构维护期限。

## 开发与验收计划

1. 建立专用分支和此 spec，锁定桌面入口与核心边界。
2. 实现原生窗口、动态范围、后台处理、逐页对比、原格式另存与退出保护。
3. 合成文档自动验证入口到输出、失败回滚、范围失效、文件保护与 Qt 交互。
4. 在纯 Windows Python 路径验证实际 WPS 的 DOC / DOCX 打开、编辑、预览、保存；私有样例只作本地验收。
5. 打包免安装 EXE；移离源码目录、去除开发 PATH 后验证启动与核心流程；记录未覆盖的干净机测试。
6. 代码审查、发布说明与验证记录。未获新指令不提交或推送。
