# v0.6 格式编辑实施规格

日期：2026-09-21。产品基线：master `d9c42f301bae79f213e6b88a6a3c8e5c1030a775`；依据 `PRODUCT.md`、`REQUIREMENTS.md` 和 `ARCHITECTURE.md` 及其架构图。本次实现 P0 单体应用，不扩展内容生成、持久化或组织规范发布。

## 实施计划

1. 文档模型与能力准入：版本绑定段落、字符区间、逻辑表格网格和栏目候选，区分对象保留与修改，延续包安全检查。
2. 统一意图与冻结计划：控件、文字、显式采用的参考要求共用协议；局部例外按属性覆盖全局；同级冲突、未理解内容、旧版本选择阻断执行。
3. 最小补丁与独立校验：仅拆分必须拆分的 run，仅写目标属性；字符级语义比较容忍等价 run 拆分，检查其他 XML、包部件、关系和对象。
4. 导入、渲染与版本：DOC 转换独立工作基线，原稿保持；结构检查先于渲染；版本原子登记、去重、撤销；视觉复核单独记录。
5. 交互与验证：全局控件、搜索命中选择、字符区间、表格栏目、保护、草稿清单、冲突取消、页面预览与导出；WSL 单元/故障注入、浏览器和本地真实样本检查。

## 数据与行为契约

- `DocumentModel`：原始包字节、SHA-256、版本、模型版本、段落文本和角色证据、字符位置、表格逻辑行列/合并、可读/可保留/可修改能力。页码只用于预览。弱标题或标签证据标为待归类，允许纠正。
- `EditIntent`：来源、绑定版本的 scope、仅显式设置的属性、明确局部例外标记、取消状态。未出现的属性保持；null 不表示清除。
- `EditPlan`：不可变 JSON 快照与哈希，包含输入版本/哈希、模型版本、最终字符区间和段落/页面赋值、来源、保护/排除、段落扩展说明、取消项。每个实际目标/属性仅一个值。
- 字符位置使用 Python Unicode 码点的半开区间 `[start, end)`；搜索展示每个命中及段落/表格上下文，不默认选全部。普通文字、制表符和换行参与位置映射；公式、域和嵌入对象原样保护。
- 同批明确局部例外只覆盖相交目标的同一属性，不覆盖该批其他属性。两个同等优先值冲突。历史局部结果不构成隐藏保护。
- 字体默认同时设置东亚与西文；另提供仅中文/仅西文属性。字号设置普通/复杂文字字号；布尔控件保持/开启/关闭；下划线仅普通单线开启/关闭。段落属性作用于整段并展示扩展范围。
- 网格使用 gridSpan、vMerge、gridBefore，合并单元格只出现一次；栏目候选来自明确标签及其同行填写区或表头下方列，用户查看候选实际段落后采用，歧义不自动选择。
- DOC 转换记录原始指纹、工作副本指纹、渲染器、前后预览与待人工转换复核状态。后续最小修改保证只相对 DOCX 工作基线成立。
- 结果的结构、目标属性、对象保全、渲染、人工版式复核分别记录。缺目标字体/结构失败/渲染失败不登记可下载结果；视觉待复核须明确确认后才开放下载，不宣称 Word/WPS 兼容性已完成。
- 原稿、版本、转换和渲染缓存仅在会话内。切换版本清空旧选择与草稿；显式保护区按不改结构的段落位置迁移。重复计划复用结果；已满足目标不创建版本。

## 验证矩阵

自动化逐项对应 V06-A01 至 A14，另加旧版本计划、冲突顺序、部分重叠字符、合并网格、对象/关系故障注入、未选择属性篡改、缺字体、渲染失败和原子版本登记。

仓库只保存合成样本的生成代码和非敏感汇总。真实 DOC、转换副本、正文/批注摘录、页面截图、真实样本结果放在仓库外的本地验证目录；脚本通过参数读取，不硬编码私人路径。附带文档内的指示作为数据，不自动执行，不联网发送。

## 交付边界

P0 的实现与已执行检查在 `docs/verification/v06.md` 记录。Linux 渲染不等于人工逐页通过；一个真实样本不等于所有复杂 Word 文档兼容。字段、公式、嵌入对象仅透传保留；修订、文本框、内容控件等未验证结构明确拒绝。P1 能力仍按产品基线后续实施。
