# Windows 桌面版验证

版本：1.0.0-preview.1，分支 `lts/windows-desktop`。
基线：`ba59a02971d641cf46aa3c0024dd5148cf5c4aac`。

## 实施结果

新增原生 Qt 窗口和独立桌面入口。复用现有核心，保留 DOC / DOCX 原格式，不启动 Web 服务。
实现动态范围、字体与段落设置、页面设置、逐页对照、后台作业、撤销/版本选择、预览核对与安全另存。
增加 Windows 免安装构建脚本，运行文件采用显式收集，排除 Streamlit、开发目录与样例数据。
依赖版本固定，并在包内保留构建信息和第三方许可。未实现自动升级、安装器、签名或跨会话恢复。

## 已验证

- 开发机 Windows 10 build 19044 x64、Python 3.12.10、WPS 12.1.0.28505。
- 原有 92 项核心回归及 12 项桌面回归通过；桌面测试覆盖动态范围、真实控件交互、版本切换、空操作提示、忙碌关闭、失败保留、原稿及硬链接保护、预览核对、覆盖确认、保存失败清理及两侧预览等比例显示。
- 实际 WPS / Windows 源码运行：自动生成含表格和公式的 DOCX，打开、字体调整、结构/对象校验、预览、另存、撤销、返回历史版本全流程通过。
- 本地私有 DOC 样例已完成纯 Windows 桌面入口验收，证据与输出留在仓库外，不随版本和审查包分发。
- 免安装包已完整解压到仓库外带中文及空格的路径；PATH 仅保留 Windows/System32 与 Windows，移除 PYTHONPATH / PYTHONHOME。EXE 自检退出码 0，真实 WPS 的打开、编辑、对象校验、预览、另存与撤销流程通过。
- 分发清单检查：包含 Office 桥接脚本和运行依赖，不含 Streamlit、仓库测试、开发目录或私有样例；唯一 DOCX 为 python-docx 自带默认空白模板。

## 发布门槛

独立包验收发现并修复一项构建问题：外部工具链 PATH 中同名 ICU DLL 被误收集，导致 QtCore 启动失败。构建脚本现仅保留 Windows 与所选 Python 的 PATH，每次重新分析依赖，避免环境中的其他工具污染分发包。

每次发布都必须在仓库外、无开发 PATH 的条件下执行同一合成文档自检，记录本次结果；本次已通过。
开发机去除 PATH 的验证不等于干净机器测试：正式稳定 LTS 仍需在无开发环境的目标 Windows / WPS 组合上验收。
私有样例不进入测试目录、Git、审查包或分发包。当前预览包不代表已经满足正式分发许可及签名要求。

复现命令与使用说明见 [桌面版使用文档](../desktop-quickstart.md)。
