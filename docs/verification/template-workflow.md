# 教案模板流程验证记录

日期：2026-09-27。开发分支：`codex/lesson-template-workflow`。预览包：`1.0.0-preview.2`。未提交、未推送，也未合入稳定维护线。

## 本次实现

- 桌面保留原布局，增加模板导入、核对、应用和导出入口，以及可折叠的正文/标题分类内容。
- 无旁批且分类、有效格式明确时自动建立基准；有旁批时提取精确锚点和有限格式要求，未理解内容、范围、例外与非格式要求保持可见并需处理。
- 校准修改实际DOC/DOCX文件，保存后重新核对属性、内容和对象保全，预览确认后才能采用。模板包包含原格式文件及来源记录，再导入重新核验。
- 教案版本记录模板来源与人工事项；保护范围延续到普通后续编辑，并可明确解除。模板已满足时不制造空版本，但记住所选标准和保护范围供后续实际修改使用。
- 模板和工作稿原件在双向另存中均受保护，包括已有文件与硬链接别名。模板与教案范围不跨文件复用段落坐标。

## 保留边界

此版本提供受控的模板处理流程，不保证任意旁批语义自动理解。回复线程、已解决批注、无法确定的主题格式、Word标题样式写入、删页、正文改写、外部课表核对、打印设置等仍按实际能力阻断或要求显式分类处理，不展示成自动通过。人工事项原文和阶段跟随模板与教案版本，未来填写要求不等于当前模板已经完成业务审核。

教案会话历史仍不自动跨会话恢复；金标准可以通过模板包重新导入。开发机隔离PATH验收不等于干净机器或其他Word/WPS版本兼容验收。设计文档中的`TPL-`场景仍需结合目标客户端与真实业务材料持续验收，不能凭一个样本宣称普遍准确率。

真实原件、批注原文、微信路径和私有派生文件均留在仓库外，本记录只保存非敏感汇总。
