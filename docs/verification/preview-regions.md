# 预览优先与教案区域标准验证

日期：2026-10-18。版本：1.0.0-preview.3。仅记录本轮新增能力，不代表所有自然语言旁批或全部教案布局均已支持。

## 已实现

- 主界面单画布结果预览；原稿在同一位置切换。详细范围、格式、分类与历史收进“更多 → 局部编辑与版本”。主要动作在整理、保存和已保存间切换。
- 四组区域按语义列头定位，支持换列序、重复表头、明确的特殊行合并。行列头宋体9磅、教学内容12磅、活动/意图9磅、特殊三行填写内容10.5磅。特定行优先，行头与填写内容分别处理。
- 四组字体字号可调整。默认保留已识别标题候选，已有明确的标题规范仍有效；只有明确选择标题同教学内容时才覆盖。
- 调整导入模板先复制候选、实际校准并复核文件，再展示模板预览供采用；取消或失败保留旧模板。采用后自动应用到工作教案。旧规则被修订的字体属性在区域内让位于新规范，其他属性及范围外规则保留。
- 既有模板包往返保持新区域定义；在新教案重新定位业务区域。无旁批自动提取和有旁批先校准的流程继续保留。

## 支持边界

缺少可靠语义列头的续表、跨不同区域且归属不明的合并单元格仍需人工核对。未导入模板时四组规则记录为用户指定的区域标准，不伪造已校准模板或文件指纹。跨会话保留实际模板请导出模板包，未新增后台自动保存或Microsoft Word COM后端。
