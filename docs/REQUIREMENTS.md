# 文序格式调整工具需求基线 v0.6

日期：2026-09-21。本文依据既有 PRD v0.5、真实教案分析及用户对全局和局部格式调整的澄清，记录下一阶段的目标需求。**本文保留目标需求语义；当前实现范围以仓库 [README](../README.md) 和 [实施与验收记录](verification/v06.md) 为准。**

相关文档：[产品目标与定位](PRODUCT.md) · [技术架构与分层](ARCHITECTURE.md) · [文档导航](README.md)。

## 1. 产品目标与范围

用户上传已经写好的 Word 文档，通过前端控件或一句话要求，调整全文中的某类文字，或某一段、某个栏目、某几个字的格式。系统准确定位，只修改明确指定的属性，保留其他内容与格式，并交付可继续编辑的 Word 文件。

核心需求同时包含两类操作：

- 全局调整：正文统一黑体五号；一级标题统一四号；全部正文行距改为固定 28 磅。
- 局部调整：只把“教学目标”栏的填写内容改为黑体五号；只把第三段加粗；只改某一句中的指定文字。

两类操作并列提供，可以在一次任务中组合，也可以在生成的新版本上继续调整。例子中的格式值是演示要求，不是任何学校或机构的正式规范。

教学内容补写、正文润色、必填业务审核、课程名称核对等不在当前产品范围内，也不成为完成格式修改的前置步骤。文档正文、批注和嵌入内容默认是待处理数据；只有用户明确采用相关规范时，批注和范文才成为候选规则来源，不自动成为执行指令。

本文中的“产品默认设计”是下一阶段的交互和行为设计，不代表当前界面已经提供，也不宣称用户逐项确认了每个默认选项。实现时必须与影响清单、范围说明和验收保持一致。

## 2. 操作入口

| 入口 | 用户操作 | 系统反馈 |
| --- | --- | --- |
| 全局格式面板 | 选择正文、文档标题、一级/二级/三级标题、表格文字等范围，再选择字体、字号等 | 展示匹配数量、具体范围、当前值与目标值；可预览命中位置和排除项 |
| 局部选择面板 | 搜索文字、选择段落/栏目/单元格，或在可定位的文字预览中选择片段 | 展示所选原文与所在区域，在该范围内设置格式 |
| 一句话修改 | 输入“正文改成宋体小四，但教学目标这一栏改黑体五号”等要求 | 转成与按钮操作一致的待应用清单；未知对象或未理解的要求原句继续显示 |
| 参考要求入口 | 使用已有参考实例入口，后续扩展到批注规则提取 | 输出候选规则供采用，不自动覆盖已经确认的本次修改 |

全局和局部均能通过控件完成，也都允许一句话表达。用户不必学会提示词才能设置常用格式。明确控件操作直接生成结构化要求，无需经过语言模型；文字解析、手工控件与已采用参考规则最终共用定位、修改和校验流程。

产品默认设计采用一个“应用修改并检查”主按钮。前端选择和文字解析先生成待应用清单，用户查看摘要与范围后点击一次即可执行，不另设重复审批页。歧义、冲突或不受支持的已选要求必须先解决或明确取消；取消的要求保留在本次记录中。

## 3. 前端界面

| 区域 | 必要内容 |
| --- | --- |
| 稿件与版本区 | 上传稿件、文件类型和处理状态、原稿/v1/v2 切换、当前修改基于哪个版本 |
| 文档预览区 | 文档页面预览、可定位的文字/结构列表、搜索、命中范围标记、修改位置定位 |
| 格式操作区 | “全局调整 / 局部调整”切换；范围选择；字体、字号、段落格式等控件；一句话输入框 |
| 待应用清单 | 本次将改哪些区域、哪些属性，目标值是什么；允许取消一项、移除某个命中、解决冲突 |
| 结果区 | 新版本预览、实际变更项、检查状态、下载 DOCX、撤销本次、继续调整 |

首版可通过搜索结果和段落/表格列表选择局部范围，页面预览承担查看和定位职责。PDF 页面上的鼠标框选不能直接视为精确 Word 节点选择；若提供页面选字，必须建立可靠对应后才能用于修改。

## 4. 修改范围

全局指“指定范围内的统一修改”，不是每次都修改全部文档。

| 范围 | 定义与交互；标注项为产品默认设计 |
| --- | --- |
| 正文 | 普通叙述段落。表格内被确认属于正文的内容通过“包含表格内正文”明确纳入；产品默认设计为勾选并显示数量。不包含已识别标题、表头、栏目标签、图表题注、页眉页脚 |
| 文档标题、一级至三级标题 | 按角色统一调整；结合样式、编号、文本和所在区域识别，允许用户纠正 |
| 表格文字 | 选择全部表格或某张表；可进一步选择列、行、单元格；表头与填写内容能够区分 |
| 全文文字（正文区和表格） | 范围名称直接注明包含正文区和表格；页眉页脚为独立范围，未支持修改时明确显示；公式、字段、未知嵌入对象继续受保护 |
| 指定段落或文字片段 | 以当前文档版本中的实际位置定位，可只修改段落中的几个字，不要求整段一起改 |
| 指定栏目 | 如“教学目标”“师生活动”；区分栏目名称与填写内容。产品默认设计为选择填写内容，并在摘要中写清楚 |
| 原样保留区域 | 用户明确标记的保护区；所有普通批量操作排除它，清单显示排除范围；修改该区需明确解除保护 |

“正文”“标题”的识别结果本身可核对。识别不确定的段落显示为待归类，不默默归入正文，也不默默遗漏后宣称全部完成。未涉及的待归类对象不阻断其他范围的明确修改；选择全局正文时，要显示可能影响覆盖范围的待确认项。

重复文本展示所在段落或表格上下文，提供“仅此处 / 勾选若干处 / 全部匹配”。同名匹配不默认全选。

页码用于预览导航；真正的修改绑定文档版本和对象位置，避免重新分页后改错对象。表格行列的定位需要考虑合并关系，不能将物理 XML 单元格顺序直接当成用户看到的列。

## 5. 格式控件与默认行为

| 类别 | 目标控件 | 行为 |
| --- | --- | --- |
| 字符格式 | 字体、字号、加粗、斜体、下划线、文字颜色 | 支持正文范围和局部文字片段；字号同时显示中文字号与磅值；中文字体与西文字体的设置范围必须明确 |
| 段落格式 | 左/中/右/两端对齐、首行缩进、左右缩进、段前/段后间距、固定值/倍数行距、与下段同页 | 修改指定段落的对应属性；单位明确，行距模式和值配套填写 |
| 页面设置 | 页边距 | 放在独立页面设置区；单节稿件作用于页面设置，不与局部文字属性混用；多节支持另行验证后开放 |
| 表格和分页扩展 | 列宽、行高规则、内边距、垂直对齐、边框、重复表头、跨页处理 | P1 逐项扩展，按对象单独选择，绝不因为改字体自动重排表格 |

每个属性默认“保持原样”。界面中展示的当前值不等于本次要设置的目标值：

- 未选中或未编辑的属性不进入本次执行清单。
- 当前选区格式不一致时显示“多种格式”，不能自动套用第一个段落的值。
- 加粗、斜体、下划线等需要“保持 / 开启 / 关闭”三种状态，不能用未勾选代表统一关闭。
- 字体、字号等控件支持清除本次设置，恢复为“保持原样”；这不等于清除文档已有格式。
- 一次修改成功后，已执行清单进入历史，下一次操作的控件恢复为“保持原样”；继续显示新版本的当前格式，不将上次目标值隐含加入下一次修改。失败时保留本次草稿便于修正。
- 中文字号转成对应数值执行，例如五号 10.5 磅、小四 12 磅；原文没有提到的字号不推测。“黑体”是字体要求，不等于开启加粗。
- 如果只选几个字却设置行距，清单需明确说明将作用于其所在段落；不能声称仅改变这几个字的行距。
- 未完整理解的文字要求继续显示为未处理项。识别出一句中的字体要求，不代表同句其他要求也已被处理。

## 6. 全局与局部组合规则

以下规则是下一阶段的产品默认设计，须写入修改计划与验收用例：

1. **按属性合并。** 同一次操作中，全局设“正文宋体小四”，局部设“第三段黑体”，第三段应为黑体小四，其他正文为宋体小四。
2. 明确的局部例外优先于同批次的全局规则；预览清单直接展示这个结果，不取决于输入顺序。不能仅因为范围更小就擅自推定它是例外，必须来自用户明确表达或选择。
3. 同一实际目标、同一属性出现两个无法确定优先关系的互斥目标时，展示冲突，由用户保留一个或取消该属性，不能随机取值。
4. 一句话解析和手工控件操作进入同一清单。用户在清单中修改目标值后，该明确修正替换对应候选值，并立即刷新摘要。
5. 新一轮操作以选中的文档版本为输入，只修改新要求明确指定的属性。上一轮结果不会因其他属性的修改而被重置。
6. 用户下一轮明确要求“所有正文统一宋体”，本轮范围内的旧黑体局部结果也会改成宋体。需要继续保留的区域，用户应明确排除或保护；系统不能保留未声明的隐藏例外。
7. 保护区始终明确显示，不因“全局”两个字自动解除。如果保护区导致无法全量覆盖，结果写明哪些位置被排除。

输入文件、作用范围或要求改变后，旧确认和旧预览立即失效。执行依据是绑定当前输入版本、已解决冲突的最终计划；不能在执行过程中重新猜测要求。

## 7. 最小修改与结果可信度

“只改指定属性”落实为四类检查：

- **内容**：文字及顺序不变，不自动润色、替换标点、补写或删除空白内容。
- **范围**：未选中的区域保持原有内容及格式，选中范围内未指定的属性保持原样。
- **对象**：图片、公式、表格合并、批注与关联关系、字段等受保护对象完整；未知对象不静默删除。
- **效果**：目标格式确实生效，文档能打开和继续编辑；生成页面预览，检查明显重叠、截断及异常分页，并标明检查方式及未完成项。

字体、字号、行距变化可能带来自然换行和重新分页，这是要求产生的结果。工具不得为控制页数擅自缩字、删内容、改变未指定的页边距或列宽。结果预览应展示版式变化，不能承诺格式改变后页码与位置完全不变。

结构与属性自动校验、渲染完成、人工版式复核必须分别记录。“成功生成全部页面图片”只证明渲染完成，不能显示成“逐页视觉检查通过”。未运行、失败、通过和待复核需要区分。

执行前保留原稿，执行后另存新版本。失败不覆盖已有版本；不能完整执行的要求显示原因，不以整体“成功”掩盖未完成项。内容、关系或文件结构保全失败时不交付最终 DOCX；带保留项的输出必须明确披露并由用户确认，不能标成完全通过。

全部目标属性已经满足时提示无需修改，不创建重复成功版本。相同输入和同一最终计划的重复请求不得重复增加版本；跨会话持久化恢复属于另外的能力，不因界面展示版本号就宣称已支持。

## 8. 文件支持与真实教案边界

P0 目标同时考虑 DOCX 与旧式 DOC。DOC 通过受控转换生成 DOCX 工作副本，保留原始文件并显示转换状态；转换后保全未通过时不进入格式执行。分别记录“原 DOC → 工作副本”和“工作副本 → 修改结果”的检查，不能把后一步最小修改通过当成前一步无损转换的证明。

真实教案包含批注、公式、插图、合并表格与嵌入对象。P0 必须用经授权的真实样本或脱敏样本验证这些对象在局部和全局格式修改中可保留；其存在不应长期成为整份文件一律拒绝的理由。

这不代表任意复杂文档都可安全读取或修改。支持矩阵分别声明“可读取 / 可原样保留 / 可修改”，按通过验收的对象和操作子集开放。未涉及且能验证保全的对象原样保留；无法验证文件结构与对象关系保全，或要求涉及未支持的修改时，阻止相应操作并说明原因。禁止仅删除当前预检拦截就宣称支持。

文件大小、页数、节数等边界在完成扩展验收前继续遵守当前实现限制，不因本文的目标扩大而自动放开。

产品编译、运行、自动化检查在 WSL/Linux 完成。Word/WPS 的实际打开和编辑结果属于客户端兼容性验收，不能以 Linux 渲染成功代替。字体环境、渲染器与客户端版本随验收记录保存，未测试的客户端不声明兼容。

## 9. 优先级与实施边界

P0 表示达到本次“真实场景可用小工具”目标的必要能力，不表示已在当前 POC 中实现。架构设计中的分步开发是完成这些目标的实施顺序，不会把真实教案所需保全能力降为可忽略项。

| 优先级 | 内容 | 用户价值与发布条件 |
| --- | --- | --- |
| P0 主流程 | 稿件导入与副本处理；正文/标题等全局控件；搜索与局部范围选择；一句话转修改清单；字体字号和常用段落属性；范围核对；保全检查；预览、撤销、导出、继续修改 | 把“统一改正文”和“只改这一处”都做稳 |
| P0 真实材料基础 | DOC 受控转换及独立基线检查；表格栏目定位；批注、公式、图片、合并关系与嵌入对象的保全子集；未指定属性不变；冲突和未理解项显式呈现 | 在明确声明且验收通过的支持范围内，让真实教案进入主流程 |
| P1 | 批注与范文规则提取增强、个人格式预设、编号整理、表格布局与分页属性、页眉页脚格式支持 | 减少重复配置，逐项扩展覆盖；编号整理不随基础格式修改自动执行 |
| 后续再评估 | 跨会话持久化恢复、批量文档、组织规范发布、复杂文档合并等 | 按后续真实需求安排，不承诺本次完成 |

现有参考实例流程保留；增加“无需提供规范或写指令，也能直接通过前端控件完成统一调整”的主路径。正文生成、润色和业务内容审核仍不在当前范围。

## 10. 验收场景

以下是目标验收用例，不是已通过记录。使用 `V06-` 前缀，以区别既有 PRD v0.5 中含义不同的 A01 等编号。验收应同时核对请求属性、非请求属性、对象保全与实际作用范围，不以成功导出文件代替。

| 编号 | 用户操作 | 应有结果 |
| --- | --- | --- |
| V06-A01 | 前端选择正文，只把字体设为黑体 | 命中的正文仅字体变化；原字号、加粗、行距保持；标题和其他区域不变 |
| V06-A02 | 正文字号五号，其他控件保持原样 | 只设置字号；多种原字体保持，不发生默认值覆盖 |
| V06-A03 | 搜索重复出现的一句话，仅选第二处，改红色 | 只改第二处对应文字的颜色，第一处与其他文字不变 |
| V06-A04 | 指定一段中的四个字加粗 | 只改这四个字，不改变同段其他字、公式、图片和批注锚点；覆盖文字跨多个 run 的情形 |
| V06-A05 | 全局正文宋体小四，同时第三段黑体 | 第三段黑体小四；其他正文宋体小四；例外清楚展示 |
| V06-A06 | 全局只改字体，同时某段只改行距 | 两种属性独立生效，局部段落同样获得全局字体 |
| V06-A07 | 选择“教学目标”填写区改黑体五号 | 栏目标签、相邻栏目、表格边框和合并关系不变 |
| V06-A08 | 选择正文范围，查看并切换“包含表格内正文” | 命中数量和标记同步变化；表头和栏目标签不被误算为正文 |
| V06-A09 | v1 中第三段黑体；在 v1 上仅改正文行距 | v2 保留第三段黑体以及其他现有格式 |
| V06-A10 | v1 有局部黑体；新一轮明确所有正文统一宋体 | 本轮选中范围的旧局部字体统一为宋体，明确保护或排除区域保留 |
| V06-A11 | 给同一范围设置互斥字号，或输入无法定位的栏目 | 冲突/未定位项显示并待处理，不猜测执行，也不静默丢弃 |
| V06-A12 | 对声明支持的、带公式、插图、批注、嵌入对象和合并表格的真实教案修改 | 目标属性正确，所有受保护对象及其关系完整，页面可核对；覆盖 DOC 受控转换的独立基线检查；对不支持或保全失败的样本准确阻断 |
